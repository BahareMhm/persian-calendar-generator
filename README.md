# Persian Calendar Generator


این پروژه یک تقویم سالانه شمسی را با استفاده از Python تولید می‌کند.

اطلاعات تقویم از طریق API دریافت می‌شود و سپس با استفاده از کتابخانه OpenPyXL ظاهر و امکانات آن ترسیم شده و در یک فایل  Excel ذخیره می‌شود.

## امکانات

- قرار گرفتن روزها به صورت پیوسته در هفته‌ها
- ایجاد ۴ ردیف خالی برای یادداشت زیر هر هفته
- نمایش تعطیلات و مناسبت‌ها


## ساختار کلی پروژه

برنامه ابتدا اطلاعات تقویم را از API دریافت می‌کند، سپس داده‌های JSON را پردازش کرده و در نهایت یک فایل Excel با ساختار و قالب‌بندی مشخص ایجاد می‌کند.

## لینک API

- API document: https://pnldev.com/fa/api-doc/calender#item-1
- API endpoint: https://pnldev.com/api/calender
